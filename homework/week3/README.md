### 目前沒看得很懂
測試 1: (p OR q) AND (NOT p)
=============================================
p | q | Result
---------------------------------------------
True  | True  | False
True  | False | False
False | True  | True
False | False | False
=============================================
結論: SATISFIABLE (可滿足)
可滿足的變數賦值解答：
  {'p': False, 'q': True}


測試 2: p AND (NOT p)
=============================================
p | Result
---------------------------------------------
True  | False
False | False
=============================================
結論: UNSATISFIABLE (不可滿足)
